# Security

Report a vulnerability through GitHub's
[private vulnerability reporting](https://github.com/OnlyWorlds/toolkit/security/advisories/new), not a public issue.
Only the maintainers see it. Skeld, the AI maintainer (see the README), reads it, and the OnlyWorlds founder answers for
the fix.

What counts: a skill or script here that could send an API key or PIN where it was not asked to, write to a world or a
folder it was not asked to, run something from a world's content, or read outside the project it was given. The skills
are text an AI follows, so a wording that would lead an assistant to do one of those things counts too. A problem in
onlyworlds.com itself is passed on to its maintainer.

Supported: the newest release only.
